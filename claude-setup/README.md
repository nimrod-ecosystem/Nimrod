# claude-setup — get guided help setting up Nimrod

This folder is a small **context pack**. Give it to an AI assistant (Claude, or another),
and it can walk you through installing and using Nimrod in plain language.

## How to use it
1. Open your AI assistant.
2. Share the files in this folder — start with `setup-guide.md` (how the assistant should
   help) and `about-nimrod.md` (what Nimrod is).
3. Ask your question: "Help me create a profile," "How do I add the photos module," etc.

## Important — please read
- This is a **third-party AI tool**, not an official Nimrod product, and not affiliated
  with or endorsed by us.
- **The conversation is not private.** Do **not** share anyone's medical or personal
  information with it. It's for setup help, not medical advice.
- For anything involving a patient's private information, use Nimrod's own local, offline
  companion — not a cloud assistant.

Later, this same help will be available inside the site itself (the local companion), so
you won't need to download anything.
