# Attributions

Third-party work that ships **in this repository**, with author, licence, source, and how it is
used. Keep it current as things are added — a licence noticed at release time is a licence
noticed too late.

This file covers what is actually here. It is **not** an audit of the whole repo: it was started
when the AAC voice clips were added, because those carry an attribution requirement, and other
things already present may still need entries. Adding one is cheap; discovering a missing one
during a release is not.

---

## Audio — the spoken words on the communication board

`web/client/aac/audio/*.wav`

| | |
|---|---|
| **What** | 17 spoken words, one per card on the two boards `/talk.html` ships |
| **Engine** | [Piper](https://github.com/rhasspy/piper) TTS — **MIT licence** |
| **Voice model** | `en_US-libritts-high`, **speaker 552** ("p112"), from [rhasspy/piper-voices](https://huggingface.co/rhasspy/piper-voices) |
| **Voice licence** | Derived from **LibriTTS** — **CC BY 4.0** |
| **Format** | mono, 22050 Hz, 16-bit WAV. 472 KB total |

**These are a synthesised voice, not a recording of a person.** That is worth stating plainly
because a folder of `yes.wav` / `love_you.wav` next to a communication board reads like somebody's
family recorded them, and they did not. It is the same voice the bedside build uses for
everything, generated by `Cici/tools/gen_aac_voice.py` in the private repo, which is also where
new words are made.

**One voice, deliberately.** A clip generated with a different engine or a different speaker is
worse than no clip at all: the board would speak in two voices, and the mismatch is more jarring
than a single word falling back to the device's own synthesiser. If a word is added to a board,
generate its clip with that tool and that speaker, or leave it — the page falls back cleanly and
writes the word on screen either way.

**What CC BY 4.0 asks of us:** attribution, which is this entry. It does not restrict commercial
use and does not require that derived work be shared alike. The 137 MB model itself is **not** in
this repo and does not need to be — only its output is.

## Fonts, libraries, symbols

The board's symbols (`web/client/aac_symbols.js`) are **drawn in-repo**, not taken from a symbol
library, so there is nothing to attribute and nothing that constrains how they are licensed
later. That was a deliberate choice and it is the reason this file is short.

Anything else added from outside — a font, a library, an icon set, a sound — gets a row here in
the same shape as the one above, **before** it is committed.
