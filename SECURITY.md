# Security

Nimrod runs on screens in people's homes and care rooms, and some of the people using it cannot
tell anyone when something is wrong. A security problem here can reach somebody who has no way to
protect themselves, so reports are taken seriously and handled privately first.

## Reporting a problem

**Please do not open a public issue or discussion for a security problem.**

Report it privately through GitHub: on this repository's **Security** tab, choose
**Report a vulnerability**. Only the maintainers can see the report.

Useful to include:
- what you found and where (a page, a file, an address on the server)
- how to see it happen, step by step
- what someone could do with it

You will get a reply as soon as the maintainer can; this is a small project run by one person, so
please allow a few days. A fix is made before anything is said in public, and you are credited when
it is, unless you would rather not be.

## What counts

Anything that could let somebody:
- see, change or delete another person's photos, recordings, messages, settings or logs
- get into a screen, a call or an account that is not theirs
- make a screen show something, play something or stop working without its owner's say
- read anything the server keeps (see the site's "everything the site's server holds" page)

## What does not need a private report

Ordinary bugs, missing features and layout problems are welcome as public issues.

## Please don't

- test against screens or accounts that are not yours
- take or keep anybody's personal data while looking
