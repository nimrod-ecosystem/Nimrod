Nimrod bricks

Every brick

Every brick is a multiple of 40 mm in every direction, with a 10 mm socket at the centre of every 40 mm square on every face, so any brick lines up with any other. The brackets and plates that join them use the same sockets. Each one has a 3D model you can download and open in any glTF viewer.

Built from bricks

Furniture made only from the bricks above. A room can draw each of these as the real brick-built piece; each one's bricks, with how many it takes, are one press away.

The list comes from bricks.json. Every part is generated from one parametric script, so a size not listed here is a number, not a new model.
