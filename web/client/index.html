Shared systems: the module bus + per-user, server-side state

A throwaway harness for the first validated slice. The counter is a trivial module wired to the real bus and the real server-backed state handle. The server (not this page) is the source of truth.

You are acting as user …. open as “alice” open as “bob” open as “dev-user”

Inputs that drive this one module: the + / – buttons, the keyboard (+ – or ↑ ↓), and the switch above — three separate sources, one counter/delta sink. The keyboard and switch were added in app.js with no change to the module.

What this slice proves

  • Server is the source of truth. Open this page in a second tab as the same user — changes converge (state round-trips through /api/state/counter; no localStorage as the store of record).
  • Users are isolated. Open as alice and bob — independent counts.
  • Inputs are interchangeable. A new source drives the module by emitting onto its topic; the module’s sink never changes.
