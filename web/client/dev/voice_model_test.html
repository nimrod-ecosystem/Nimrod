your own voice model (Euphonia)

2026-10-02. A speech model trained on ONE person's voice: Google's Project Euphonia toolkit fine-tunes Whisper on ~100 phrases. This page records the phrases with the screen's own recorder (a phrase shown, read, saved, the next), exports them in the folder layout Euphonia's notebook reads, and shows the commands that convert the result and start the speech service on it - for that one person.

Not covered here: training or converting a real model (nothing is downloaded or run), a real microphone, or a real speech service. The service's own folder check is in web/speech_service/test_service.py. Recognisers below are fakes that speak the recorder's events.
