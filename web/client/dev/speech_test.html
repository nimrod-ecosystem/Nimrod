No microphone is opened by anything on this page. The matcher is a pure function over TEXT, and the recogniser is injected — which is the same seam that lets a local engine replace the browser's later. That is not only a testing convenience: Chrome's SpeechRecognition streams audio to Google, so being able to swap it is the difference between shipping this and not.
