theme surfaces (Claude Design's theme checklist, 2026-10-10)

Design: "When a theme is added, every line below needs an answer for it." Mike's standing rule: when a decision is made, the question is what test proves it. This suite is that test, for every line Code can check from data: every theme in theme.js is on the checklist (theme_surfaces.js siteThemes), and every theme answers every required line, or is named on that line's known-gap list below. A NEW theme missing a required surface fails here; today's gaps are named, not hidden; and a gap that gets filled fails until it is crossed off, so the lists only shrink.
