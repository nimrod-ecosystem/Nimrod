does a directory handle survive a page reload?

This is a PROBE, not a suite. It answers a question about the browser, not about Nimrod, and the answer decides whether "tidied up whenever this is opened" is true or wishful.

Two halves, and they have different answers:

  1. Does the handle itself survive? Testable here with no picker and no prompt, because navigator.storage.getDirectory() hands over a real FileSystemDirectoryHandle for free.
  2. Does the PERMISSION survive? Only answerable with a folder somebody actually picked, because the origin-private one needs no permission at all. That is the button below, and it needs a human — reload the page afterwards and press Check remembered folder.
