making a board

A caregiver opens this over the board and is called into the corridor. The person the board belongs to is then looking at a form they cannot fill in, cannot cancel, and cannot talk through — their voice replaced by somebody else’s settings screen. So the editor closes itself when nothing has been touched for a few minutes, and hands the work back as a draft rather than saving half a board or throwing an afternoon away. That is the check this suite exists for; the rest is about not losing anybody’s words.
Nothing is uploaded, and this asserts it rather than saying it. A picture is a {sourceId, path} reference to a file on the person’s own machine. The suite checks that what gets saved is that reference and not the URL the picker displayed — a folder listing revokes its own object URLs, so a stored URL would go blank later with no error anywhere.
