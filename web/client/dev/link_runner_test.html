link_runner — carrying values along links

No server needed. links.js is structure only; this is the thing that makes a link carry traffic: it reads a createLinkStore(), checks each link with classifyPatch, and republishes a value from the FROM port's topic onto the TO port's topic — appending a provenance hop, keeping the source's timestamp, applying a range map only where both ranges are declared. A link that cannot carry stays in status() with its reason rather than vanishing.
