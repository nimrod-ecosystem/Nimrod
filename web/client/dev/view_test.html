view — the thing the kiosk should have been made of

A view is an arrangement of modules, as a module — the same pattern director.js already uses one level down. It matters because it turns swapping what is on a screen from a bespoke function into destroy one, mount another, using lifecycle the runtime already has. And because a view owns its own chrome, a swapped-in arrangement brings its own camera corner with it by construction rather than inheriting whatever was mounted before.
