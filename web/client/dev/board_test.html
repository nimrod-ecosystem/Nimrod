the communication board

A board must never be the thing someone uses to summon help. Selections go out as say, which stays in the room — never as notify, which reaches another device. The verb is the boundary, and this suite asserts it.

AAC users build motor plans: Yes is there, reached without looking. Software that silently reflows a layout as vocabulary grows takes that away, and it is the most common way well-meaning AAC software fails. So the first two sections are about position, and they matter more than anything else here.

Not covered here. Recorded audio clips — the private build speaks every card from a .wav because the Pi often has no TTS voice installed at all, which would make this board silent on the one machine it most needs to work on. That is a real deployment gap, not a test gap, and it is flagged in the report rather than papered over. Also not covered: any judgement about whether these sixteen words are the right sixteen for anybody but the person they were assembled for.
