MACHINE HEALTH — measured on THIS box
Two channels from one key. SPACE is bound to pressgame/press, so it drives the game — and the same physical press also appears as edge_down / edge_up with its real hold, which the game itself does not react to.

It talks and hums. "Wait", "Go", a reward word, and gentle lines if you mash during the wait — spoken through the output bus, so the person's own routing decides how. The hum underneath is synthesised, so it needs no music folder — and it ducks under every cue, because a screen has one pair of ears.

Hold the key down to see heldMs grow while requiredHoldMs stays 0 — that is the difference between "could not let go" and "was asked to hold".
SCRIPTED INPUT — this box has no Wayland input-injection tool, so the presses below were dispatched as real keydown/keyup events through the real keyboard adapter rather than made by a finger. Everything downstream of the adapter — bindings, edges, timing, the frame numbers above — is genuine.
