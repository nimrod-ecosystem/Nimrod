lesson lines

A page for a tool, not a person (web/tools/make_lesson_clips.py, proposal_lesson_voice_clips_20261104.md). It runs the Lessons panel's own spokenLines() over every class that comes with the site, so a recording made ahead of time is made for exactly the words the panel says. The tool calls window.lessonLines(name); the learner's name is handed in by the tool, never put in this page's address. Opened by hand, it lists the counts with no name.
