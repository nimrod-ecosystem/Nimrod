scanning — the loop, extracted

Fifteen seconds is not a UI default. It is her number, with her reason, carried across verbatim: "she understands the task but needs time to process the cue before signaling." A suite that let it drift would be letting the whole point drift.

The scan loop lifted out of the private scan_yesno.js so a board is not the only thing that can have one. It owns an ordered list, an index and a clock, and knows nothing about cards, speech or the DOM. The interval is now stepMs rather than dwellMs — the glossary recorded that collision with a plan to move the scanning sense when scanning was extracted, and this is that moment.

Not covered here. The board on top of this — cards, speech, the AAC emit — is Tier 2 and is not written. Neither is anything about whether 15 seconds is right for a second person; that is a bench and clinic question, and the number is carried rather than justified.
