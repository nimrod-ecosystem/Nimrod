color_picker — palette as data, pure helpers, one small renderer

No server, no network. The palette is a DEFAULT (Rule 1): a field can bring its own, and a Design-supplied palette replaces this data outright. What is tested here is what must hold for ANY palette — names a person can hear, hex values that normalise, a nearest-name answer for a colour that is not on the list — plus the one property of THIS palette that justifies it: every chromatic swatch reads (3:1) against both the lightest and the darkest shipped theme ground.
