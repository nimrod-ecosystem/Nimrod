Room notifications: event → object → does (room add-ons §6)

Design: rules are event → object → does, each with a Test button; defaults wake → lamp and cat, message → speaker, call → fireplace, visitor → door. The on-screen cue always comes too; objects only add to it. The editor is switch-reachable (one button per control, the way out first), and a room with it open puts itself back after the lifted-panel time with nobody touching it — the product's invariant.
