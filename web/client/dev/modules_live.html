modules.html?all=1 — same run, same judging, on the public page in the site's own palette.

Why it moved. This harness mounted every module and reported whether it drew anything. modules.html described every module and could mount one. Two pages doing the two halves of one job — and the half that PROVED anything was a dev file nothing linked to, while the page everybody lands on could only describe. The judging now lives in module_audit.js, so there is one implementation instead of two that drift, and the run happens where somebody can find it.

The old hardcoded palette went with it. This page set .stage{background:#0A3323}, which is --ink's own value — every module here was drawing ink-coloured text on an ink-coloured background at a contrast ratio of exactly 1.00, in all five themes, and it did not move when the theme did. Some of “the text is hard to read” almost certainly came from looking at this page rather than at a real screen.
