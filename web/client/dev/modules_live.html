Every module, actually running

Not a description. This page mounts every module in the catalog, gives each one the same context the kiosk gives it, lets it run, and then reports what happened. Everything below is the module itself, live, in a 330×240 box. Scroll and look at them.

What this proves and what it does not. DREW means the module mounted without throwing and put pixels on screen. It does not mean the module is correct, useful, or finished — a clock showing the wrong time would still say DREW, and on the first run of this page educational said it while drawing only its arrows around an empty content stage. The numbers on each card are what was measured; the box above them is the actual evidence. This page replaces "I was told it works" with "I can see it running", which is a lower bar than working and a much higher one than a list.

It runs signed out, on browser storage, with no account and no server data — the same path a stranger gets. Nothing here touches your screens.
