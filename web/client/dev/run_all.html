every client suite, one page

Each suite runs in its own iframe, in small parallel batches, and reports the number it printed for itself. This does not re-judge anything — a suite that lies to itself lies here too. It exists so a change to a shared primitive can be checked against everything that uses it without forty navigations.

An amber no summary row usually means your browser, not the suite. A hidden window throttles every tab to about one timer per second, and suites that mount real modules live in short waits. Measured: youtube_test finishes in 2.0s in one iframe and soak_test in 23s alongside three others — both report no summary when the window is hidden. Check a suite on its own before believing this page about it.

Needs the server: web/server/.venv/Scripts/python -m uvicorn app:app --port 8000. Suites listed as no summary did not finish inside the timeout, which is usually a real hang and worth opening on its own.
