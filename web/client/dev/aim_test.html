the aim

She cannot hold a mouse. If a position can only arrive as a mouse event, the module built to answer “did I do that?” can never answer it for her.

comet.js read pointermove off its own canvas, and pond.js did the same and called its copy aim(), and module-input-spec.md told module authors not to assume a pointer exists at all. Three private copies of one idea. aim.js owns it now: a normalized (x, y) from whatever is driving the screen, with a mouse as the first producer and a camera tracker as a later one that nothing downstream can tell apart.

These are pure-unit where they can be — aim.js and cursor.js need no server — and the comet section mounts the real module. Needs the server only for the module registry's sake: web/server/.venv/Scripts/python -m uvicorn app:app --port 8000.
