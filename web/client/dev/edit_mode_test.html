edit mode — edit any module in place (Mike, 2026-10-02)

"Every module should have an edit mode ... You wouldn't have to be in the edit dashboard to edit a module. So you could click on a button or piece of furniture or whatever else and have access to any options for it." A panel in edit mode takes presses on it as CHOICES (the words on a sign, its picture, the panel); the chosen thing's options show in the builder's options panel when there is one, or in a card in the panel. Done, Escape, the ✎ corner, the verb, or a while with no press leaves it. No server needed.
