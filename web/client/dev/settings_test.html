settings — the universal menu shell + declared fields (slices 1 & 2)

No server, no network. The cursor rules are asserted pure; the shell is driven through the same imperative moves the kiosk's key handler uses, because the kiosk has no input bus. A fake bus covers the path a host with one would take.

Slice 2 adds settings_fields.js, and the bulk of what is below is stepValue hammered on its own. That is deliberate: it is the entire one-button contract in one pure function, and the combination space of a big options surface cannot be tested end to end — so the resolver gets hammered alone and the wiring gets tested once.
