prefab.js — TYPE → PREFAB → INSTANCE

H1's correction is why this is three layers, not two: a prefab carries a DEFAULT (headless off), and an instance of that prefab can still switch it. This suite proves the resolution chain — type defaults, then a prefab's overrides, then one instance's own overrides — and, most importantly, the diff behavior that keeps a prefab's own later edits from being drowned out by instances that only ever "agreed" with the old value.
