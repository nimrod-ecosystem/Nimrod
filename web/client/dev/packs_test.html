docs/PACK_SCHEMA.md, private repo: "A pack is built FROM A SOURCE. It is never recalled from memory... A pack without one does not load." This file is where that sentence stops being documentation and starts being enforced — validatePack refuses a pack with no source, the same way every other safety rule in this codebase is a check rather than a promise.

This suite validates the loader and its checker. It does not wire any module to consume a pack — Trivia, Word Forge and Lessons each have their own existing content model and their own answer for how a loaded pack should merge with what they already have, and that is a per-module decision for the next pass, not a guess made here.
