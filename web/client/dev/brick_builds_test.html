brick_builds — furniture built from Nimrod bricks, drawn in the rooms

Mike, 2026-10-02: "Can we make things like desks from Nimrod bricks and then have a merged version that is actually used in the dashboards? Then you can go into it and edit if you want." The site has no mesh renderer, so the merged version a room uses is the build's baked FRONT PICTURE, tinted with the piece's own colour. This checks: the index of builds agrees with the published assemblies; the 2D room draws a brick-built desk and side table by default, drawn on request, and drawn when the picture will not load; edit mode offers the piece's Look and "Open its bricks"; the 3D room draws a brick-built piece as one face.

Needs the server (it fetches the published assemblies and pictures).
