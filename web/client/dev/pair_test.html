pair — the phone end of the QR code

Somebody has just pointed a phone at a screen in a room. This page turns that into a claimed screen with as close to zero typing as possible. Three people arrive here and it has to serve all three: scanned and already signed in (one button), scanned and signed out (sign in, then come straight back with the code intact), and typed the address by hand (an empty box).

The one subtle thing is that the code has to survive an OAuth round trip, which leaves this page entirely and returns through a callback that knows nothing about it. Losing it there is the failure that sends somebody back down the corridor to squint at the screen again.

Run the server first: web/server/.venv/Scripts/python -m uvicorn app:app --port 8000 (only the live panel needs it; every check below runs against a fake).
