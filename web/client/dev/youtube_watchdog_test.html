The failure this fixes: a bedside screen found frozen on a loading spinner. A video that never starts fires neither onEnded nor onError — a hung request is not a player error — so the director waited forever for a segment/done that was never coming. Driven with an injected player that simply never plays, and a fake clock, so no network is involved. Run the server first: web/server/.venv/Scripts/python -m uvicorn app:app --port 8000.

And the second door, found 2026-08-27: a video that PAUSES after playing fired nothing at all, and PLAYING had already disarmed the watchdog — so the screen sat on a paused video forever and the one person in front of it cannot press play. The invariant: a screen must never enter a state that only an input can leave, when the person in front of it cannot give that input.

And the third, found 2026-08-30: PLAYING disarmed the watchdog permanently, so a video that froze after starting was watched by nothing at all — and the one segment/progress it sent at the start meant a container could not tell a 40-minute video from a dead one.
