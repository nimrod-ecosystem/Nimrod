Two ends, each its own app on its own sockets, through the REAL server and a REAL WebRTC call (the browser's fake camera and microphone): a screen (a real kiosk with a Call panel and a Board panel) and a caller (the real call page, signed in as somebody holding only a CALL-ONLY permission - a call is only a call, 2026-10-14).
