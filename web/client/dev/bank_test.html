the shared bank

A format change that silently emptied somebody's word bank would be unrecoverable.

Somebody building a syllabus writes sixty words once. Making them write the same sixty again in a second format so a second game can use them is the tax that makes people stop after the first game. So both games read one document — and every bank written before this file existed still parses exactly as it did, which is the assertion this suite cares about most.
