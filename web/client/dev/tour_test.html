the guided tour

A tour overlay a person cannot leave is precisely the shape the safety invariant forbids: a screen must never enter a state that only an input can leave, when the person in front of it cannot give that input. The first two sections are that property, and both carry a negative control — the guard is disabled, the check is confirmed to go red, and it is restored. A green line proving nothing is the failure mode this project has already been bitten by.
