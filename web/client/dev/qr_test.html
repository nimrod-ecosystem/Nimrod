qr — the encoder, read back out of its own symbol

EVERY CHECK ON THIS PAGE CAN PASS AND A PHONE CAN STILL FAIL TO READ THE CODE. These prove the bytes are right. Contrast, module size, screen glare and camera focus are not testable from here. The acceptance test is a real phone scanning the real pairing screen — the gallery at the bottom is there to be pointed a camera at.

The strong check here is not structural. It is a round trip: the test reverses the encoder — unmask, read the zigzag, de-interleave, strip the error-correction blocks, parse the byte-mode header — and asserts the original string comes back. That single assertion covers the placement order, the mask, the interleave and the padding at once, any of which produce a symbol that looks perfect and scans as nothing. The Reed–Solomon blocks are then checked against an independent GF(256) implementation written in this file, so a shared bug in the field arithmetic cannot hide.

No server needed — this page imports one module and nothing else.
