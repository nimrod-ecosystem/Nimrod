Makerspace & fabrication

Print Your Own

The basic Nimrod bricks. Every brick is a multiple of 40 millimetres (mm) in every direction. Every face has a 10 mm socket in the middle of every 40 mm square, so any brick lines up with any other. The brackets and plates that join them use the same sockets. Every part is made by one build123d script (a program that makes the shape from numbers). So a new size is a new number, not a new model.

Status, honestly

Each part below has a 3D model. It is a GLB (a 3D model file), and any program that opens GLB files can show it. Which file is the design

The STL is what you print. The build123d script is the design.

An STL is only the finished shape. It is good for printing. It is no use for changing a size or adding a feature. Every part here is made by one build123d script, written in the Python language. So a brick of a size not listed here, or a longer bracket, means changing a number. It does not mean drawing the shape again from nothing.
