Course A · Flagship

Set Up and Use an AAC Board

Build a real augmentative-and-alternative-communication board — symbols, categories, and a voice — in a browser, on a library computer, with nothing to install. Leave with a board you or a family member could use the same day.

Try the AAC board now → Read the documentation
Adults & children 60 min short · 90 min long Nothing to install

What you need

  • A computer with a browser — Chrome, Edge, or Firefox, any from the last few years.
  • Nothing to sign in with. The board runs with no account.
  • Optional: a USB switch, or any USB/Bluetooth gamepad, to try scanning instead of a mouse or touchscreen.
  • A quiet-ish room. This is a listening-and-talking course.
Short version Longer version Documentation

Short version — about 60 minutes

A working board by the end of the hour.

For a first exposure, or a single library visit — My Digital Life's standalone 60-minute format. No homework, no second session required.

  1. 0:00–0:10 — What AAC is, in one sentence, and why "communication board" is a better search term than any product name. Open the AAC board together.
  2. 0:10–0:25 — Tour the default board: categories, the core-word set, and how a tap speaks the word out loud. Everyone tries a few taps.
  3. 0:25–0:45 — Personalize: add or edit a few cards for something real to the person building it — a name, a food, a activity. Change the board size if the default feels too small or too dense.
  4. 0:45–0:55 — Try switch scanning: turn on scanning, and drive the board with the space bar or a plugged-in switch instead of touching cards directly.
  5. 0:55–1:00 — Where to go next: the longer course, and the handout below.

Longer version — about 90 minutes

A board built for one specific person.

A Maker-Monday-length session for a patron (or a caregiver, or a classroom) who wants to leave with a board that actually fits somebody's life, vocabulary, and physical access needs.

  1. 0:00–0:15 — Recap of the short version's ideas for anyone new, then straight into the board.
  2. 0:15–0:40 — Vocabulary: work from the core 36-word set outward. Build a category around the person's actual routine — meals, people, a specific hobby — instead of the shipped example set, which is one family's board and says so on its own card.
  3. 0:40–1:00 — Access method: try touch, then mouse, then switch scanning with real timing. Tune hold time and scan speed instead of accepting the defaults — this is the part a 60-minute session has to skip.
  4. 1:00–1:15 — Dwell selection as a second option for someone who can point but not press reliably; compare it against scanning for the same person.
  5. 1:15–1:30 — Save, review, and talk through what to change next time. Handout and documentation link below.

Documentation

What this course is built on, plainly.

The board

A grid of cards, each with a symbol and a word. Tapping a card speaks it aloud and can add it to a sentence strip. Boards are editable: add, remove, or re-theme cards, resize the grid, and switch between a starter board and one built from scratch.

The core word set

A default 36-word starter vocabulary, built as one family's worked example — it has no food or drink cards by design, and the module says so on its own settings card so whoever picks it knows to expect a rewrite for a different life.

Scanning & dwell

Two access methods for someone who can't reliably tap: scanning highlights cards one at a time and a single press selects whichever is lit; dwell selects whatever a pointer or gaze rests on for a set time. Both are tunable — hold time, scan speed, repeat behavior — per person, not per device.

The switch

Anything that sends a keypress or a gamepad button works as a switch — a $75 commercial adaptive switch, or an arcade button wired to a microcontroller for about $15. Nothing needs a custom driver; the browser sees a keyboard or a gamepad either way.
