Course D

Games for the Classroom

Trivia, Word Forge, and algebra practice — three accessible learning games a teacher, tutor, or homeschool parent can reconfigure on the spot: different questions, different word lists, different difficulty, no code.

Try Trivia → Try Word Forge → Try Algebra →
Kids & teens Educators 60 min short · 75–90 min long

What you need

  • A computer with a browser — nothing to install.
  • No account needed to try any game from the links above.
  • A text file or spreadsheet of your own content, if you want to build a custom pack in the longer session.
  • Any switch, gamepad, or keyboard the class already set up in Course B — these games accept the same input.
Short version Longer version Documentation

Short version — about 60 minutes

Play all three, reconfigure one.

  1. 0:00–0:15 — Quick tour: Trivia (multiple choice, partial credit for a later correct guess), Word Forge (build words from letters or definitions), and Algebra (guided equation practice).
  2. 0:15–0:40 — Play each for a few rounds. Notice what's easy to change from the settings gear on each panel — question count, difficulty, category.
  3. 0:40–0:55 — Swap in a different content pack for Trivia or Word Forge — a different subject, a different reading level — without leaving the page.
  4. 0:55–1:00 — Where a teacher would go next: the longer session, for building a pack from scratch.

Longer version — about 90 minutes, Makerlab-style

Build a content pack for your own class.

  1. 0:00–0:20 — Recap, then open the pack format: a plain list of questions, answers, and (for Trivia) distractors — the same shape whether it's vocabulary, history, or a unit test review.
  2. 0:20–0:55 — Build a real pack together for a subject the group chooses. Load it into Trivia or Word Forge and play it immediately — no publishing step, no waiting.
  3. 0:55–1:15 — Algebra's guided practice: how difficulty steps up, and how a teacher sets the range of problems for a specific unit.
  4. 1:15–1:30 — Save and share the pack; discuss where else it could be reused — the homeschool page uses the exact same packs.

Documentation

What this course is built on, plainly.

Content packs

Trivia and Word Forge both read from a plain content-pack format — questions, answers, and metadata — so "make a new quiz" is editing a file, not touching game code. The same mechanism this proposal's own program listing borrows its shape from.

Trivia

Multiple choice with partial credit for a later correct guess — full points for a first try, fewer for each subsequent one, so attempting is still rewarded.

Word Forge & Algebra

Word Forge builds vocabulary from definitions or letters; Algebra steps through guided equation practice. Both accept the same switch, gamepad, or keyboard input as Course B's games — no separate setup.
