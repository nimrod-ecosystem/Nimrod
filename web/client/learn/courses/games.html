Course E

Games for the Classroom

Trivia, Word Forge and algebra practice. These are 3 learning games made for people of all abilities. A teacher, tutor or homeschool parent can change them on the spot: different questions, different word lists, a different level. No code is needed.

Try Trivia → Try Word Forge → Try Algebra →
Kids & teens Educators 60 min short · 75–90 min long

What you need

  • A computer with a browser — nothing to install.
  • No login needed to try any game from the links above.
  • A text file or spreadsheet of your own material, if you want to build your own pack in the longer session. A pack is a file of questions or words.
  • Any switch (one big button), game controller or keyboard the class set up in Course C. These games work with the same controls.
Short version Longer version Documentation

Short version — about 60 minutes

Play all 3, then change one.

  1. 0:00–0:15 — Quick tour: Trivia (multiple choice, partial credit for a later correct guess), Word Forge (build words from letters or definitions), and Algebra (guided equation practice).
  2. 0:15–0:40 — Play each for a few rounds. Notice what is easy to change from the settings gear on each part: how many questions, how hard they are, and which set of questions.
  3. 0:40–0:55 — Swap in a different content pack for Trivia or Word Forge — a different subject, a different reading level — without leaving the page.
  4. 0:55–1:00 — Where a teacher would go next: the longer session, for building a pack from scratch.

Longer version — about 90 minutes, Makerlab-style

Build a content pack for your own class.

  1. 0:00–0:20 — Recap. Then look at how a pack is laid out: a plain list of questions, answers and, for Trivia, wrong answers to choose from. The layout is the same for vocabulary, history or a review for a unit test.
  2. 0:20–0:55 — Build a real pack together, on a subject the group chooses. Load it into Trivia or Word Forge and play it. There is no publishing step.
  3. 0:55–1:15 — Algebra's step-by-step practice: how it gets harder, and how a teacher chooses which problems to use for one unit.
  4. 1:15–1:30 — Save the pack and share it. Talk about where else it could be used. The homeschool page uses the very same packs.

Documentation

What this course is built on, plainly.

Content packs

Trivia and Word Forge both read content packs. A pack is a plain file of questions, answers and a few details about the pack, such as its name and where it came from. So "make a new quiz" means changing a file, not changing the game's code. This proposal's own program listing borrows the same idea: it is a plain file that somebody edits.

Trivia

Multiple choice. A right answer on the first try earns full points. A right answer on a later guess earns fewer. So trying is still rewarded.

Word Forge & Algebra

Word Forge builds vocabulary from definitions or letters; Algebra steps through guided equation practice. Both accept the same switch, gamepad, or keyboard input as Course C's games — no separate setup.

Ways to play, honestly

All three games accept scanning and pointer input the same way the rest of the site does. Voice control exists in the codebase — nine fixed spoken phrases mapped to actions, no AI involved — but it is deliberately not switched on in the product today. The reason is privacy, not readiness: a browser's built-in speech recognizer sends audio to Google's (or Apple's) servers to be transcribed, which is a real consideration on a shared library kiosk, not just in someone's home. If a future class demos it, the page and the kiosk itself should say so plainly, in those words — the same rule that already applies to any camera on this site.

Make your own pack

A content pack is a JSON file (a kind of text file). Any AI (artificial intelligence) can write one with you.

Three sample packs on this site were built this way, from real sources rather than an AI's memory: Cleveland Museum of Art — who painted it?, Who wrote it? — famous opening lines, and Cleveland Public Library — history facts. Try one now from the games above — they're in the same pack picker as every built-in set.

The rule that keeps a pack honest

A pack is built from a source, never from memory. An AI asked "give me trivia about the Great Gatsby" is remembering. That is where made-up facts come from. An AI given the actual text and asked to pull questions out of it has a different, much safer job. Every pack records where its content came from. A question nobody can trace is a question nobody should trust.

Paste this into any AI, along with a source (a book, an article, a fact sheet):

Make me a Nimrod trivia pack from the source below.

Rules:
  - Every question must be answerable FROM THE SOURCE. Do not use anything you
    already know. If it is not in the text, it is not a question.
  - Four answers each, one correct, three plausible and wrong.
  - Mark difficulty very easy / easy / medium / hard.
  - Add a one-line "explain" for each, so a wrong answer teaches something.
  - Give each question a "source": the sentence or section of the source it
    comes from, quoted or named, so a person can find it.
  - Return ONLY valid JSON in the shape below, no commentary.

{ "schema": "nimrod.pack.v1", "kind": "trivia", "name": "...",
  "description": "...",
  "source": { "name": "...", "url": "...", "licence": "...",
              "attribution": "..." },
  "generated": "YYYY-MM-DD",
  "items": [ { "question": "...", "answers": ["...","...","...","..."],
               "correct": "...", "difficulty": "easy",
               "category": "...", "explain": "...",
               "source": "<where in the source this comes from>" } ] }

SOURCE:
[paste the text, or the link, here]

Load the file the AI gives you from the game's own settings menu. Choose "Load your own pack," then pick the file or paste its text. There is no code to write and nothing to install. The pack is yours as soon as you load it. Nobody else sees it.
