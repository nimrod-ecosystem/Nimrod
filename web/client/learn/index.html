A proposal, built to be tried — not read

Adaptive technology instruction you can try before it's approved.

This is a working proposal for TechCentral's Technology Associate role, built on Nimrod — an open-source platform for adaptive technology, communication boards, and switch access. Every course below runs real software in your browser, right now, on this page. Nothing here is a mockup.

What this is

The posting's own duties, done — not described.

TechCentral's Technology Associate posting asks for adaptive-technology support, training sessions for adults and children, instructional and promotional materials, program listings, and makerspace fabrication. Each section of this page is one of those, built on real software rather than proposed in the abstract.

Adaptive technology

AAC boards, switch access, and scanning — the AAC course and the device setup course.

Training, adults & children

Every course lists who it's for and how long it runs, in TechCentral's own session formats — see the calendar.

Instructional materials

Each course page is a real handout: audience, duration, what you need, an outline, and a link straight into the running module.

Makerspace & fabrication

Print Your Own — modular parts built from the same brick system, with build123d source beside every STL.

Courses

Four courses. Each one runs in a browser, with nothing to install.

Every course has a short version and a longer one, an audience tag, and a "try it" link straight into the live module — no separate demo environment.

Program listing

A proposed calendar, in TechCentral's own session shapes.

My Digital Life's 60-minute standalone format for adults, Maker Monday's 90 minutes, Makerlab's 60–90 for kids and teens, and Tech Help's 2-hour 1-on-1 blocks — matched to real content rather than invented for this page. This listing is a content pack (calendar.json): updating it is editing that file, the same way a teacher edits a game's word list.

Nothing above has run yet — this is the proposed program, not a record of sessions held. Two entries are marked Coming: the games they depend on aren't built.

Try it

The same screen a patron would use. Press play.

Pictures, a live camera view, a clock, and Word Forge with the AAC vocabulary from Course A — the same four-panel layout a real setup would use, running the same code. No account, no install.

Nothing here asks for your camera — the live-view panel is a public camera, on purpose. Want to try the AAC board instead of Word Forge? The AAC course links straight to it.
