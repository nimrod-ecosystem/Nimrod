For families

The same games. A parent's view instead of a classroom's.

Nothing here is a separate product — it's Course D's Trivia, Word Forge, and Algebra, plus quests and progress tracking, framed for one family running lessons at home instead of a room of students.

What's here

The three learning games

Trivia, Word Forge, and Algebra — the exact same modules a TechCentral class would use, with the exact same content-pack system. A parent builds a pack around whatever the week's lesson is, the same way a teacher would.

Full documentation →

Quests

A running list of goals — finish a pack, hit a streak, try a new subject — that turns a week of practice into something with shape, instead of an open-ended pile of worksheets.

Try it →

Progress

A plain record of what's been done and how it went — for a parent who wants to see the shape of a month, not just today's session.

Try it →

Nothing new to learn

This page reuses Course D's modules exactly as they are. If a family later visits TechCentral, the games their child already knows are the same ones running there.
