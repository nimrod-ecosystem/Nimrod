# Nimrod core concepts

The ideas everything in Nimrod is built on, ranked: when two pull against each other, the higher one wins. Mike set
the list and its order on 2026-10-27 and expects to add to it over time. Each concept may change; when one does, it is
changed here, and git keeps what it said before.

1. **Leave everyone better off than you found them.**

2. **Everything is modular. Turtles all the way up. Turtles all the way down.**
   Every piece is built from the same kind of parts, and any part can hold or sit inside others, so anything can be
   swapped, combined or reused.

3. **No absolutes. A rule is a setting with a sensible default.** (The few real rules are declared by Mike.)
   A hard rule written for one person locks out the next. Warnings warn; they don't block.

4. **Defaults give everyone the best experience; a particular need is a setting.**
   If every need became a default, the site would turn into the sterile eyesore people with special needs meet
   everywhere.

5. **Build everything, withhold nothing.** (Free and open source, MIT; the free version always exists.)
   Nothing is held back to sell later.

6. **Take as little user data as possible, and never sell it.**
   Privacy is what people trust us with. Data stays on their own system by default.
